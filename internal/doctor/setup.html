New here? notary doctor --generate-key --trusted-keys-out KEYFILE creates a fresh key pair. The private half is printed as an export NOTARY_SIGNING_KEY=... line (or written 0600 to --key-out, which is refused inside a repository); the public half — the one base64 line NOTARY_TRUSTED_KEYS_PATH names for verify, replay and report — is written to KEYFILE at mode 0644. A public half is not a credential, so it may live in a checkout; the private half belongs outside one, or in the environment.
